# 游戏屏幕测距弹道计算器
基于 Python + tkinter 实现的屏幕像素测距工具，用于游戏内标定比例尺，测量两点实际距离并计算低抛炮弹飞行时间。全局热键唤起全屏半透明遮罩，在画面上点击标记点位完成测距。

## 功能简介
1. **屏幕像素比例尺标定**：在游戏画面标记已知实际距离的A‑B两点，建立像素与实际千米的换算关系。
2. **距离测量**：标定完成后标记C‑D两点，自动算出C、D之间实际地面距离。
3. **弹道飞行时间计算**：给定火炮初速，计算**低抛弹道炮弹飞行时间**，超出最大射程给出警告。
4. **两种工作模式**
    - 右键开局：AB标定模式，鼠标滚轮可微调AB基准距离，更新比例尺。
    - 左键开局：复用上次内存内保存的比例尺，直接测量CD距离，滚轮锁定不可调。
5. 参数内存记忆：标定好的比例尺、AB基准距离保存在内存，关闭遮罩窗口不会丢失，程序完全退出才清空。
6. 全屏置顶半透明遮罩，屏幕绘制标记点、连线、描边文字提示，ESC键关闭遮罩窗口。

## 操作完整步骤
1. 使用**管理员身份**运行 `python 测距仪04.py`
2. 控制台打印启动信息，程序后台等待热键。
3. 切换到游戏画面，按下 `F7`，弹出全屏半透明遮罩。

> ⚠️遮罩生效后**第一次鼠标点击会被程序忽略**，仅用来区分左键/右键模式，第二次点击才真正记录标记点。

### 模式一：右键开局 —— AB标定模式（新建比例尺）
1. F7唤起遮罩，**第一次点击鼠标右键（会被忽略）**，程序进入标定模式。
2. 第二次点击：标记A点（绿色圆点+文字A）
3. 第三次点击：标记B点（绿色圆点+文字B，绘制AB绿色虚线）
4. 鼠标滚轮上下滚动：±5米调整AB基准实际距离，自动更新比例尺。限制50‑1500米。
5. 第四次点击：标记C点（红色圆点+文字C）
6. 第五次点击：标记D点（红色圆点+文字D，绘制CD黄色虚线）
7. 自动计算CD实际距离 + 低抛飞行时间；超过火炮最大射程会输出警告。
8. 任意再次点击屏幕 / 按ESC：关闭遮罩窗口，**标定参数保存在内存中，下次F7可以复用**。

### 模式二：左键开局 —— 复用已有比例尺快速测距
> 需要内存中已经有过一次成功标定记录。
1. F7唤起遮罩，**第一次点击鼠标左键（会被忽略）**，进入复用模式，滚轮被锁定无法修改AB。
2. 第二次点击标记C点（黄色圆点C）
3. 第三次点击标记D点（黄色圆点D，绘制CD黄色虚线）
4. 直接输出CD距离与弹道飞行时间。
5. ESC或再次点击关闭遮罩。

## ⚠️重要注意事项
1. **必须管理员权限运行！** `keyboard`全局热键库，普通权限无法捕获F7全局按键，会无响应。
2. 所有标定参数只保存在**内存**，关闭整个Python程序后所有标定数据丢失，下次启动程序默认重置AB=200m。不会写配置文件保存。
3. 遮罩是半透明顶层窗口，不要调整窗口大小，全屏模式适配显示器分辨率。
4. 本程序仅做**低抛弹道计算**，没有高抛弹道逻辑；没有考虑风阻、海拔、炮弹下坠修正等游戏内复杂物理，仅理论数学估算飞行时间，仅供参考。
5. AB基准标定：A、B两点不能点击在同一个位置，否则比例尺计算报错。
6. AB基准距离限制：最小50米，最大1500米，滚轮不会超出该区间。

## 常见问题排查
### Q：按F7没有反应
- 没有以管理员运行终端/IDE；关闭程序，右键终端选择【以管理员身份运行】再启动脚本。

### Q：提示缺少模块 ModuleNotFoundError: No module named 'keyboard'
- 执行 `pip install keyboard` 安装依赖库。

### Q：提示无有效比例尺！请右键重新标定AB
- 当前使用左键复用模式，但是内存中没有上一次标定结果。需要使用右键完整跑一遍AB标定流程。

### Q：滚轮滚动没有效果
- 滚轮只在【右键开局的AB标定模式】可用；左键复用模式滚轮被锁定。需要标记完A、B两点之后滚轮才会生效。

## 程序限制
1. 无配置文件持久化，退出程序标定数据全部清空。
2. 仅低抛弹道计算公式，无高抛解算。
3. 仅支持全屏遮罩，不支持窗口化局部区域测距。
4. 不支持多显示器，建议使用主显示器。

## 技术原理简述
1. tkinter 创建全屏置顶半透明遮罩画布捕获鼠标点击坐标（像素）
2. 用户标记A、B两点像素距离，结合输入的AB实际距离，计算每像素代表多少千米：`scale_km_per_px = AB实际千米 / AB像素长度`
3. 标记C、D，计算像素距离 × 比例尺得到CD真实千米距离。
4. 使用抛射运动公式，根据初速、射程解算低抛仰角，再计算炮弹飞行时间。
